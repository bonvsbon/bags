# Step 6 — Protocol: verify package จริง + เก็บตัวอย่างข้อความ SCB

> เป้าหมาย: หา packageName จริงของ SCB + เก็บตัวอย่างข้อความ noti จริง 10–20 อัน
> เพื่อใช้ออกแบบ parser ในเฟสถัดไป (ยังไม่ parse ในเฟสนี้)
>
> ⚠️ งานนี้ทำบน **มือถือ Android จริง** เท่านั้น (ต้องมีบัญชี SCB + ทำธุรกรรมจริง)

---

## 0. เตรียมเครื่อง (ครั้งเดียว)

```bash
npm run build && npx cap sync android && npm run android:open
```
- Android Studio เปิดขึ้น → เสียบมือถือจริง (เปิด USB debugging) → กด Run ▶
- แอป "เงินทอน" ติดตั้งลงเครื่อง

---

## 1. เปิดสิทธิ์ + เข้าโหมด verify

1. เปิดแอป → **เปิดแอปจริง** → ล็อกอิน (บัญชีเดโมก็ได้)
2. **เพิ่มเติม → ตั้งค่า** → เลื่อนไปส่วน **"ดักการแจ้งเตือนธนาคาร"**
3. กด **"เปิดหน้าตั้งค่าสิทธิ์"** → เปิดสิทธิ์ให้ "เงินทอน" → กดกลับ
4. เปิดสวิตช์ **"โหมดส่องหา (verify)"** ← ตอนนี้แอปจะเก็บ noti "ทุกแอป" ชั่วคราว

> โหมด verify จะเห็น noti ทุกแอป (รวมแชท) เป็นเรื่องปกติของขั้น verify — ปิดทันทีเมื่อเสร็จ

---

## 2. ทำธุรกรรม SCB จริง (ให้ครบหลายแบบ)

ทำทีละอย่าง แล้วรอ noti เด้ง เก็บให้ครบชนิดเท่าที่ทำได้:

- [ ] **โอนออก** (พร้อมเพย์/เลขบัญชี) จำนวนเล็ก ๆ
- [ ] **รับโอนเข้า** (ให้คนอื่นโอนมา หรือโอนระหว่างบัญชีตัวเอง)
- [ ] **จ่ายบิล / สแกน QR** ร้านค้า
- [ ] **ถอน/กดเงิน** (ถ้าสะดวก)
- [ ] **เงินเดือน/ดอกเบี้ยเข้า** (ถ้ามีจังหวะ)

> ยิ่งหลายแบบยิ่งดี — parser เฟสหน้าจะได้เห็นทุกรูปแบบข้อความ

---

## 3. ดึงข้อมูลออก

1. กลับมาหน้าตั้งค่า → ส่วน "ที่ดักได้ล่าสุด" จะเห็นรายการเด้งเข้ามา
2. **สังเกต packageName** ใต้ชื่อธนาคาร/ในแต่ละรายการ — SCB ใช้ package อะไรกันแน่?
   - ตรงกับ `com.scb.phone` ไหม? ถ้าไม่ตรง จดค่าจริงไว้
3. กด **"ส่งออก JSON"** → คัดลอก (หรือถ้าคัดลอกอัตโนมัติไม่ได้ จะมีกล่องให้เลือกคัดลอกเอง)
4. เอา JSON มาวางใน [`plan/fixtures/scb_samples.md`](fixtures/scb_samples.md) แล้วกรอกคอลัมน์ "ค่าที่ถูกต้อง"

---

## 4. ปิดโหมด verify (สำคัญ)

- ปิดสวิตช์ **"โหมดส่องหา (verify)"** กลับ
- ถ้า packageName จริงของ SCB **ไม่ใช่** `com.scb.phone` → แจ้ง Claude Code ให้แก้ใน `BankCatalog.java`
- เปิด checkbox **SCB** → ทดสอบว่าตอนนี้ดักเฉพาะ SCB ที่มีตัวเลขจริง

---

## 5. ส่งมอบ (Definition of Done ของ Step 6)

- ✅ packageName จริงของ SCB (ยืนยันแล้ว)
- ✅ ตัวอย่างข้อความจริง 10–20 อัน กรอกใน `scb_samples.md` พร้อม "ค่าที่ถูกต้อง"
- ✅ ปิด verify + commit โดย `CAPTURE_ALL_FOR_VERIFY`/verify ไม่ค้างเป็นเปิด
